# Vulkan 渲染管线简介

此次我们将介绍渲染管线的基本概念和工作原理，了解计算机如何绘制三角形

## 三角形怎么表示

可以在一个**二维**坐标轴上用三个坐标来表示一个三角形

例如 `[(0, 0), (1, 0), (0, 1)]` 就表示一个三角形

### 为什么方形绘图已被淘汰

方形绘图在上世纪90年代中被 [NVIDIA NV1](https://zh.wikipedia.org/wiki/NV1) 使用，但现在基本被淘汰，核心原因：

- **三角形天然共面**（3点必共面），四边形的4个顶点不一定共面，光栅化时会产生扭曲瑕疵
- **三角形是渲染的"原子"**——最简单的多边形，任意多边形都可三角化，反过来不行
- **硬件实现简单**——三角形扫描线光栅化规则高效，四边形需要复杂的前向差分算法
- **API 生态统一**——DirectX/OpenGL 都以三角形为基本图元，NV1 无法兼容标准 API

简单来说就是四边形的4个顶点不一定共面，光栅化有歧义，需要更复杂的算法来处理

因此现代图形 API（Vulkan、DirectX 12、OpenGL）都以三角形为基本图元

但怎么把这些坐标显示到屏幕上，这就需要 Vulkan 渲染管线

## Vulkan 渲染管线概览

Vulkan 渲染管线步骤如下

1. Input Assembler: 输入装配器
2. Vertex Shader: 顶点着色器
3. Rasterizer: 光栅化器
4. Fragment Shader: 片段着色器
5. Color Blending: 颜色混合
6. Frame Buffer: 帧缓冲

### 输入装配器

在输入装配器中，会将顶点坐标列表和索引缓冲组合为三角形的顶点数据

例如顶点列表 `[(0, 0), (1, 0), (0, 1), (1, 1)]` 加上索引 `[0, 1, 2, 1, 3, 2]`，就组成了两个三角形 `[0,1,2]` 和 `[1,3,2]` (没错，这里两个三角形组成了一个矩形)

### 顶点着色器

在顶点着色器中，会处理所有顶点坐标并进行变换，例如旋转、缩放、平移

例如将顶点 `(1, 0)` 旋转 90° 后变为 `(0, 1)`，这通过矩阵乘法实现：

```
| cos90°  -sin90° |   | 1 |   | 0 |
| sin90°   cos90° | × | 0 | = | 1 |
```

顶点着色器对每个顶点独立运行，通常还会将顶点从模型空间变换到裁剪空间 (MVP 矩阵变换)

### 光栅化器

光栅化器将顶点着色器输出的三角形转换为屏幕上的像素片段（fragment）。在此之前，GPU 会自动完成裁剪、透视除法等固定步骤

例如一个三角形顶点为 `(0,0), (3,0), (0,3)`，光栅化后会被填充为：

```
(0,3) *
      |**
      | ***
      |  ***
      |   ***
(0,0) *----***---- (3,0)
```

- 每个 `*` 代表一个被覆盖的像素，光栅化器会判断哪些像素在三角形内部，并为它们生成片段数据 (位置、深度、插值属性等)

### 片段着色器

片段着色器将处理光栅化器输出的所有片段数据，

它采用插值数据 (例如纹理、法线、光照等) 输出每个像素的颜色、深度、透明度等属性

### 颜色混合

将片段着色器输出的颜色、深度、透明度等属性混合到帧缓冲区中

### 帧缓冲

Excellent! 这就是最后的步骤，将帧缓冲区中的图像输出到屏幕 (通过交换链 Present) 或保存为文件

## 两种阶段

上述渲染管线有两种阶段：

- 固定功能 (Fixed Function): 无太多自定义选项，大多数由GPU硬件实现
    1. 输入装配器
    2. 光栅化器
    3. 颜色混合

- 可编程 (Programmable): 可以自定义渲染管线的每个阶段，实现更复杂的渲染效果
    1. 顶点着色器
    2. 片段着色器
    - 通过编写GLSL着色器代码实现

## 为什么这些是必须的

虽说可以直接编写一个简单的C程序来实现，但这样会慢很多

因为CPU只能处理顺序指令，就像一个流水线一样，即使算上现代SIMD指令

而GPU可以并行处理，每个像素可以独立处理，这使得渲染速度更快，这是连现代CPU都无法比拟的

但这个性能提升是需要代价的，就是在GPU编程上有更多的限制
