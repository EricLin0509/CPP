# 指针运算

跟基本类型一样，指针也能进行运算

这用于指针的移动，即改变指针所指向的内存地址

注意事项:

- 指针运算只能用于能确定大小的类型 (如 `int`, **已经定义**的结构体等)，否则编译器会报错 (如 `void` 类型指针)
- 不能对空指针或者悬空指针进行运算，否则会导致未定义行为

## 支持的运算符

指针支持加法和减法运算，但不支持乘法、除法和位运算 (需要先强制类型转换成如 `uintptr_t` 类型的整数)

- `+`: 指针加法，即增加指针所指向的内存地址
- `-`: 指针减法，即减少指针所指向的内存地址
- `++`: 指针自增，即增加指针所指向的内存地址一个单位
- `--`: 指针自减，即减少指针所指向的内存地址一个单位

也支持进行比较运算

- `==`: 指针相等，即两个指针所指向的内存地址相同
- `!=`: 指针不等，即两个指针所指向的内存地址不同
- `<`: 指针小于，即两个指针所指向的内存地址小于
- `>`: 指针大于，即两个指针所指向的内存地址大于
- `<=`: 指针小于等于，即两个指针所指向的内存地址小于等于
- `>=`: 指针大于等于，即两个指针所指向的内存地址大于等于

## 语法

### 加法

```cpp
int a[2] = {1, 2};
int *p = &a[0];
p += 1; // p 指向 a[1]
```

### 减法

```cpp
int a[2] = {1, 2};
int *p = &a[1];
p -= 1; // p 指向 a[0]
```

## 示例

假设现在有个函数，用于单次输出一个整数

```cpp
void print_int(int *val, int index)
{
    std::cout << "index: " << index << ", value: " << *val << "\n";
}
```

创建一个数组

```cpp
int a[5] = {1, 2, 3, 4, 5};
```

现在希望使用上面的函数，输出数组中的每个元素

```cpp
int *p = a;
for (int i = 0; i < 5; i++)
{
    print_int(p, i);
}
```

但是这样只能输出第一个元素

此时需要使用指针运算，将指针移动到下一个元素

### 使用指针运算

```cpp
int *p = a;
for (int i = 0; i < 5; i++)
{
    print_int(p, i);
    p += 1; // 指针移动到下一个元素
}
```

### 使用指针自增

```cpp
int *p = a;
for (int i = 0; i < 5; i++)
{
    print_int(p, i);
    p++;
}
```

### 倒序输出

可以使用指针减法或指针自减

```cpp
int *p = a + 4; // 指针指向数组的最后一个元素
for (int i = 0; i < 5; i++)
{
    print_int(p, i);
    p--; // 指针移动到上一个元素
}
```

### 使用指针比较

使用指针比较也能实现上述功能

```cpp
int *start = a;
int *end = a + 4;
int i = 0;
while ((start + i) <= end)
{
    print_int(start + i, i);
    i++;
}
```

### 原理

假设现在有个 `int` 类型的指针 `p`

```cpp
int a = 10;
int *p = &a;
```

我们尝试输出 `p` 和 `p + 1` 的地址值

```cpp
int *next = p + 1;
std::cout << "p: " << p << ", next: " << next << "\n";
```

输出如下

```
p: 0x7fffffffd62c, next: 0x7fffffffd630
```

可以看到 `next` 的地址值比 `p` 大了 4 个字节

而 `int` 类型的大小刚好是 4 个字节

再尝试改为 `double` 类型

```
p: 0x7fffffffd62c, next: 0x7fffffffd634
```

可以看到 `next` 的地址值比 `p` 大了 8 个字节

而 `double` 类型的大小刚好是 8 个字节

所以指针运算的原理就是在指针存储的地址值的基础上加上或减去相应类型的字节数，从而得到新的地址值

这就是为什么如 `void` 类型指针不能进行指针运算的原因，因为 `void` 类型没有大小
