# 数组

数组 (`std::array`) 是 C++11 STL 库中的一种序列容器，用于存储固定大小的元素序列

相比数组，数组是固定大小的，不能动态扩展或收缩，因此在内存使用上更加高效

## 与普通数组的区别

与普通数组 (`array[]`) 相比，`std::array` 有以下特点

| 特性 | `array[]` | `std::array` |
| :--: | :-----: | :--------: |
| 内存布局 | 连续内存 | 连续内存 |
| 运行时开销 | 无 (在启用优化的情况下) | 无 |
| 指针解引用 | 支持 (直接访问元素) | 不支持 |
| 大小跟踪 | 传递给函数时丢失 | 使用 `size()` 方法 |
| 边界检查 | 无 | 使用 `at()` 方法 |

- 通常情况下都推荐使用 `std::array`
- 只有在需要配合 C API 时才使用普通数组

## 语法

需要包含 `array` 头文件

```cpp
#include <array>
```

### 创建数组

```cpp
std::array<类型, 大小> 数组名;
std::array<类型, 大小> 数组名 = {元素1, 元素2, 元素3, ...};
```

## 示例

现在声明一个包含 5 个整数的数组

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};
```

### 访问元素

有两种方式访问元素

- `[]` 索引操作符
- `at()` 方法


#### `[]` 索引操作符

`[]` 索引操作符用于访问数组中的元素，类似于普通数组

```cpp
arr[0] = 1; // 将第一个元素设置为 1
```

#### `at()` 方法 

`at()` 方法用于访问数组中的元素

相比 `[]` 索引操作符，`at()` 方法会进行越界检查，如果越界会抛出 `std::out_of_range` 异常

所以推荐配合 `try-catch` 块使用

```cpp
try
{
    arr.at(0) = 1; // 将第一个元素设置为 1
}
catch (const std::out_of_range& e)
{
    std::cout << "[ERROR] Index out of range!" << std::endl;
}
```

### 直接访问底层连续存储

使用 `data()` 方法可以获取数组的底层连续存储地址 (首元素地址)

这配合需要指针解引用的函数非常有用

```cpp
void printArray(int *arr, size_t size)
{
    std::cout << "Array = ";
    for (size_t i = 0; i < size; i++)
    {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;
}
```

```
printArray(arr.data(), arr.size());
```

- 返回的指针使得范围 [`data()`, `data()` + `size()`) 始终是有效范围
- 容器为空 (大小为 0) 时，返回的指针仍然有效但不可解引用

### 填充数组

使用 `fill()` 方法可以将数组中的所有元素填充为指定的值

```cpp
arr.fill(0);
```

### 交换两个数组

使用 `swap()` 方法可以交换两个数组的内容

```cpp
std::array<int, 5> arr1 = {1, 2, 3, 4, 5};
std::array<int, 5> arr2 = {6, 7, 8, 9, 10};

arr1.swap(arr2);
```

- 相比其他序列容器，`std::array` 的 `swap()` 方法需要保证两个数组的大小相同
