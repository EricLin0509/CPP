# 容器适配器

容器适配器是 C++ STL 库中的一种类模板，它不是真正的容器

而是基于已有容器 (如 `deque`、`vector`、`list`) 提供特定接口限制的封装层

## 主要特点

- **不提供**迭代器: 无法直接遍历元素
- **不提供**随机访问: 只能按特定规则访问元素
- 接口**受限**: 只暴露符合其语义的操作

## 容器适配器类型

- [`stack`](栈/README.md)：栈
- [`queue`](队列/README.md)：队列
- [`priority_queue`](优先队列/README.md)：优先队列
- [`flat_map`](平铺映射/README.md): 平铺映射 (C++23新增)
- `flat_set`: 平铺集合 (C++23新增)
