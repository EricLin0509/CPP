# 左值与右值

左值是指一个被存储在一些可定义的内存位置中的对象

右值是临时对象或字面量，不能取地址，通常是表达式的中间结果

## 左值示例

假设定义一个变量 `i`

```cpp
int i;
```

那么 `i` 就是一个左值，因为 `i` 可以取它的地址，也能修改它的值

```cpp
int *p = &i;
i = 10;
```

## 右值示例

假设定义一个变量 `j` 并赋值为 `i+2`

```cpp
int j = i + 2;
```

那么这个 `i+2` 就是一个右值，因为 `i+2` 不可以取地址，也不能修改它的值

```cpp
int *p = &(i + 2); // 错误
i + 2 = 4; // 错误
```

## 左值引用

左值引用是指一个引用一个左值的变量

```cpp
int i = 10;
int &j = i; // j 是 i 的左值引用
```

但不能引用一个右值

```cpp
int &k = 2; // 错误
```

- **注意**: 有个例外，就是 `const` 左值引用可以引用右值

```cpp
const int &k = 2; // 这是允许的
```

- 这是因为编译器会先创建一个值为 `2` 的临时变量，然后引用这个临时变量

## 右值引用

```cpp
int &&ref = 10; // ref 是 10 的右值引用
```

具体请查看 [右值引用](../../现代C++特性/右值引用/README.md) 章节

## 左值与右值的转换

可以用左值创建一个右值

```cpp
int i = 10;
int j = i;
```

也可以用右值创建一个左值 (通常在使用数组时)

```cpp
int v[10];
*(v + 2) = 4; // v + 2 是一个右值，而 *(v + 2) 是一个左值
```

## 常见误区

### 误区1: 函数返回值和操作符始终是右值

如果函数返回值是个左值引用类型，那么这个结论不成立

现在有个全局变量 `globalVar` 和一个函数 `func` 并返回 `int&` 类型

```cpp
int globalVar = 10;
int &func()
{
    return globalVar;
}
```

那么可以直接对函数赋值

```cpp
func() = 20; // 这是允许的
```

更简单的例子就是索引操作符 `[]`，它永远生成一个左值

```cpp
int arr[10];
arr[2] = 4;
```

### 误区2: 左值都可以修改

如果左值被声明为 `const`，那么它就不能被修改

```cpp
const int i = 10;
i = 20; // 错误
```

### 误区3: 右值不能被修改

这个结论只有在基本数据类型上成立，如果右值是类，那么它仍然可以被修改 (例如调用成员函数修改成员变量)

```cpp
class Dog {
    private:
        std::string sound;
    public:
        Dog() { }

        void makeSound()
        {
            sound = "woof";
        }
};
```

```cpp
Dog().makeSound(); // 这就修改了右值中的成员变量
```
